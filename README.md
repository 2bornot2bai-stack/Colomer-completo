# Colomer Web + Hub Premium Demo v4

Demo visual y funcional para GitHub Pages.

## Archivos

- `index.html`: web pública premium demostrativa.
- `hub.html`: Hub operativo demo con login, leads, documentos, clientes, lectura IA simulada y vista cliente.
- `styles.css`: diseño premium dark navy/oro/azul.
- `app.js`: lógica de demo, formulario, localStorage y periodo de 15 días.
- `favicon.svg`
- `.nojekyll`

## Subida a GitHub Pages

1. Crea o abre el repositorio.
2. Sube todos los archivos de este ZIP en la raíz.
3. Activa GitHub Pages desde `Settings > Pages`.
4. Abre la URL pública.

## Reiniciar demo

Añade `?resetdemo=1` a la URL:

`https://usuario.github.io/repositorio/?resetdemo=1`

## Aviso importante

Esta maqueta usa datos ficticios y `localStorage`. Sirve para presentar el flujo comercial, no para producción.

Para versión real harían falta:
- login seguro,
- base de datos,
- almacenamiento documental,
- roles y permisos,
- backups,
- trazabilidad,
- RGPD, privacidad y textos legales revisados.
